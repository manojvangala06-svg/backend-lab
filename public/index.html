RESTful API Endpoints

Structured collection endpoints following industry standards with proper HTTP methods and status responses.

GET 200 OK
List All Books with Filters
GET /books?search_q=&order_by=&order=&min_price=&max_price=&limit=&offset=

Supports partial search (`search_q`), column sorting (`order_by`), direction (`order`), price range (`min_price`, `max_price`), and pagination (`limit`, `offset`).

GET 200 / 404
Get Book by ID
GET /books/:id

Retrieves a single book resource by its primary key ID. Returns 404 if the book does not exist.

POST 201 / 400
Create New Book
POST /books

Creates a new book. Enforces validation rules: title and author must be non-empty strings, price must be a non-negative number.

PUT 200 / 404
Update Existing Book
PUT /books/:id

Updates title, author, or price for an existing book. Returns 404 if the target ID is not found.

DELETE 200 / 404
Delete Book
DELETE /books/:id

Deletes a book by ID. Returns 200 OK with success confirmation, or 404 if record is absent.

Debugging Solutions

4 Lab Debugging Resolutions

Investigation, root cause analysis, and permanent fixes for the 4 common backend errors explored in the lab.

⚡

Bug 1: EADDRINUSE Port Conflict

Problem: Server crashed on startup because another process was already occupying port 3000.

- app.listen(3000); + server.on('error', (err) => { + if (err.code === 'EADDRINUSE') + startServer(port + 1); + });

Fix: Implemented automatic port failover listener trying next available port.

📁

Bug 2: Module Not Found (Wrong Path)

Problem: `routes/books.js` failed to require `db.js` due to an extra parent directory jump.

- const db = require('../../db'); + const db = require('../db');

Fix: Corrected relative import path to properly reference the root database module.

🗄️

Bug 3: SQLite Table Typo

Problem: SQL queries failed with `SQLITE_ERROR: no such table: books_table`.

- SELECT * FROM books_table + SELECT * FROM books

Fix: Corrected the SQL query to target the actual initialized table name `books`.

⏱️

Bug 4: Missing Await on DB Call

Problem: Route returned an empty pending Promise object before database query completed.

- const books = db.all(query, params); + const books = await db.all(query, params);

Fix: Added `await` to ensure asynchronous SQLite promise resolves before sending response.
